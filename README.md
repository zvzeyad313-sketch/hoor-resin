# Hoor Resin Store

A modern, artisanal e-commerce platform for **Hoor Resin Art**, specializing in unique handmade resin pieces.

## 🚀 Features

- **Product Catalog**: Beautifully designed grid with fade-up animations.
- **Search & Filter**: Find products by name or category.
- **Product Details**: Dedicated modal for detailed product information.
- **Custom Orders**: Specialized form for requesting unique designs.
- **WhatsApp Checkout**: Two-step checkout process (Cart -> Shipping Info) that redirects to WhatsApp with a pre-filled order summary.
- **Admin Panel**: Full control over products and orders (Add/Edit/Delete).
- **Responsive Design**: Optimized for mobile and desktop.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Database/Auth**: Supabase
- **Styling**: Vanilla CSS (Artisanal Gallery Design System)
- **Deployment**: Netlify
